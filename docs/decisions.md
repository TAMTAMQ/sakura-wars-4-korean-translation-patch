## 2026-10-26: 엔딩 스태프 이름 열의 데이터 배치

이슈 #7 추가 제보의 두 이름 열이 행마다 밀리는 문제를 고친다. 기존 「이름 + 전각 공백 두 개 + 이름」은 앞 이름 길이가 다르면 둘째 열의 x가 달라진다. 첫 이름은 모두 한글 성/이름 사이 반각 공백 하나를 가지므로 그 플래그는 유지하고, 한글 칸 10개까지 투명 한글 타일로 채운다. 첫 이름 길이와 글꼴 크기에 관계없이 둘째 열 시작이 같아진다. 기존 공유 문안은 복사하지 않고 레이아웃 명세가 소비한다.

칸을 늘린 문자열은 현재 ASCR 포인터 표에서 참조하지 않고 번역 슬롯의 예약 용량에도 속하지 않는 공간에 넣는다. 파일 크기·명령·행 수·스크롤 시점은 유지한다. config/ending-credits-layout.json에 명시한 공간만 허용하며, 원본 해시/포인터/문자열/보호 구간과 최종 빈 글리프를 빌드에서 검사한다. 이 결정은 프레임 저하 해결 또는 실행 검증 완료를 의미하지 않는다.
