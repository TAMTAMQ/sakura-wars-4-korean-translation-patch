# 대사 검수 진행 기록 · 2026-10-22

사용자 요청에 따라 게임 내 표시 확인은 범위에서 제외했다. 이 기록의 정적 인코딩·용량·산출물 검증은 게임 화면 확인이나 전 문장의 의미 검수 완료를 뜻하지 않는다.

## 현재 범위

`assets/translation/review/dialogue_review.html`에서 원문, 교정 전 문안, 현재 공유 문안, 판정과 사용처를 함께 본다. 교정 전 문안은 덮어쓰지 않고 나란히 보존한다. 편집 권위본은 계속 `assets/translation/units/`이며 검수표는 생성한 조회용 자료다.

- 텍스트가 있는 검수 대상 문안 19,365개. 대화 외에 선택지·안내·용어도 포함한다.
- 원문/번역을 읽고 대조한 문안 6,698개. 이 중 확정 5,207개, 표현 차이를 대조했으나 통일이 미확정인 문안 1,458개, 원문 추가 확인 필요 29개, 문맥 추가 확인 4개.
- 아직 문장별 의미 검수를 하지 않은 문안 12,667개.
- 일반·음성 번역 차이가 있던 문안 1,727개는 모두 대조했다. 대조했다고 해서 남은 말투 차이를 전부 합격 처리한 것은 아니다.
- 교정·추출 경계·원문 복원 기록이 있는 문안 554개. 이 중 패치 바이트가 실제 바뀐 문안은 435개, 사용처는 748곳이다. 경계/원문만 복원한 항목을 실제 번역 교정 수로 더하지 않는다.

**전체 대사 검수는 아직 완료되지 않았다.** 자동 전수 검사와 실제 읽은 범위를 분리해 집계했다. 40,338개 사용처에 대한 정적 검사는 수행했지만 이를 전 문장의 의미 검수로 집계하지 않는다.

## 주요 교정

- `物で釣るというのは、どうかと`의 비판을 제안처럼 옮긴 “물건으로 꾀는 건 어떨까요”를 “물건으로 꾀는 건 좀 그렇네요”로 교정.
- 글리신이 상대를 데리러 온 상황의 `迎えに`와 자신의 신랑을 뜻하는 `ムコ` 교정. 여성 화자에게 사위가 된다는 오역 제거.
- `邪魔はさせん`의 “방해하지 않겠다”를 “방해하게 두지 않겠다”로 교정.
- `落とすまで`의 “떨어뜨릴 때까지”를 “떨어뜨리겠다”로 교정.
- `ノージンジャー`의 의미 없는 음역을 “어쩔 수 없네요”로 현지화.
- 제도와 주민을 말하는 문장의 마을/도시 표기 및 공연 `レビュー`의 레뷰 표기 정리. 단어가 같다는 이유로 모든 `町`를 치환하지 않았으며 프랑스 소도시 문맥은 유지했다.
- 천장 함정, 명령을 따르다, 다음 방문/대전의 今度, 출발하는 화자의 작별 인사 방향, 한국어 말더듬 소리, 불필요한 피동과 어색한 조사를 교정.

음성 문자열 경계 복원은 72개 문안·225개 사용처다. `off_b`가 문자열 중간을 가리키는 경우에 실제 앞부분까지 편집 범위를 넓혔으며 포인터와 타이밍 값은 변경하지 않았다. 실제 데이터에 이미 있던 앞부분은 유지했고, 일본어 잔재·오역이 확인된 경우만 번역했다.

일반 대사 69개 문안·349개 사용처는 구 한글 코드가 일본어로 잘못 읽힌 원문을 `research/legacy/original_txt/`의 동일 파일·표 번호로 복원했다. 해당 `originals/disc` 파일도 구 한글 코드이므로 일본어 원본 바이너리에서 복호화했다고 주장하지 않는다. 근거 파일의 SHA-256과 원문 행을 기록했다. 그중 24개 문안은 같은 문장 또는 이미 대조한 음성 문안을 참조하도록 연결했다. 홍란의 동일 대사가 일반 대사에도 반영되도록 두 사용처 모두 들어가는 용량으로 정리했다.

추가로 옷장 장면의 `聞く/聞かれる`를 묻다가 아닌 듣다로, 이별 장면의 `しめっぽい`를 축축하다가 아닌 울적하다로 교정했다. 관객이 연극을 봐 주어 배우가 힘을 얻는 문장의 수혜 관계도 복원했다. 낫토의 끈적함과 네버 기브 업의 말장난은 끈적함·끈기로 연결해 한국어에서도 성립하게 했다.

전체 근거와 수정 전후 원문은 `assets/translation/review/20261022-*/changes.json`에 있다. 각 배치의 `before.zip`은 교정 직전 권위본과 위치 파일을 보존한다. `decisions.jsonl`의 판정은 원문 및 모든 변형의 내용 지문에 묶여 있으므로, 문안이 바뀌면 검수표에서 다시 미검수로 표시된다.

## 이어서 검수할 위치

`work/qa/dialogue/single-review.json`의 0–4939번은 읽었다. 다음 미검수 시작은 **4940번**이다. 이미 별도로 검토한 관용 표현과 겹치는 항목은 `decisions.jsonl` 지문으로 확인한다. 이 배열은 이번 작업 당시 만든 순서 고정 목록이며 권위본이 아니다.

원문이 전용 글리프 코드로 깨진 항목, 필살기/문장 일부로 잘린 항목은 원문을 연결·복원한 뒤 판정한다. 화자별 말투가 달라야 하는 짧은 응답은 원문이 같다는 이유만으로 하나의 어미로 강제 통일하지 않는다.
