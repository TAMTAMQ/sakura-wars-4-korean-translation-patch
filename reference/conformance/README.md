# Conformance cases

다른 구현에서도 같은 입력과 기대 결과를 사용할 수 있는 검증 자료다.

- `write-plan.json`: 원본 byte, 영역과 쓰기 계획, 선택적인 검증기 응답·감사 대상 출력
- `roundtrip.json`: 경계 ID, 원본 byte와 재구성 byte

각 사례는 `input`, `expected`(accept/reject), 설명을 갖는다. 성공 사례의 `output`은 정확한 기대 byte다. 쓰기 거부 사례의 `rejection`은 실패 원인도 구분하여, 다른 검사에서 거부된 결과를 통과로 세지 않게 한다. byte는 0–255의 정수 배열이고 영역은 시작 포함·끝 제외 범위다. `audit_output`이 있으면 계획을 적용한 후 그 별도 출력을 감사한다.

기계어 사례의 `verifier`는 원천 조립, 연속 해석과 재조립에 대한 고정 응답이다. 실제 ISA 정확성은 해당 프로필의 검증이 맡으며, 여기서는 쓰기 검증기가 그 응답을 어떻게 검사하는지 확인한다. JSON의 `schema_version: 2`는 실제 입력을 포함하는 형식이며, 이전 형식은 Rust 시나리오 이름만 제공했다.

Rust 실행기는 인접한 `../rust/`에 있다. 다른 언어는 이 JSON을 소비하는 실행기를 구현하면 된다. 자료를 제품 입력 형식으로 채택할 필요는 없다.
