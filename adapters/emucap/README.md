# emucap 실행 검증 어댑터

실제 게임의 산출물 소비를 관측하는 도구로 [emucap](https://github.com/mcpads/emucap)을 선택했을 때 적용한다. 설치와 에뮬레이터별 절차는 공개 배포 문서를 따른다.

검증할 산출물의 강한 해시를 실행 중인 매체의 식별 정보에 연결한다. 비교하는 해시의 대상과 범위가 같아야 하며, 여러 파일로 이루어진 매체는 각 구성 파일과 실제 로드 대상의 관계를 확인한다.

실행 결과에는 다음을 남긴다.

- 정확한 산출물과 실행 환경의 식별 정보
- 시작 조건, 관측 경로, 기대 결과와 실제 결과
- 스크린샷·추적·메모리 등 근거의 식별 정보
- 상태 불러오기·메모리 변경·루틴 호출 등 개입과 우회한 경로

증거 범위는 정적으로 연결된 소비 경로, 시작 조건과 관측한 상태로 정한다. 동등성이 입증된 경로는 근거를 공유하고 차이가 있는 경로를 추가 확인한다. 적재·초기화를 주장할 때는 같은 산출물에서 해당 경계 이전의 상태로 시작하거나 새 실행으로 경계를 통과한다.

실행 자료 중 저작권이나 로컬 환경 정보가 포함된 자료는 `evidence/private/`와 `.emucap/`에 두고, 공개 저장소에는 배포 가능한 요약과 식별자를 남긴다. 의미·시각 품질 검토와 배포 판단은 `AGENTS.md`의 증거 구분을 따른다.
